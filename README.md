# s25
Ce projet a pour objectif la vérification de la stabilité et la monotonie des modèle d'arbre de décision boosté, notamment XGBOOST et LightGBM.

# Depandence: 
Pour compiler et exécuter ce code il sera necéssaire d'installer certaines bibliothéque: \\

XGBoost: https://xgboost.readthedocs.io/en/stable/install.html \\

LightGBM: https://lightgbm.readthedocs.io/en/stable/ \\

panda: pip innstall panda 
...

# Implementation : 
Le développement de ce projet est réalisé en \textbf{Python}. 
Tout le code source se trouve dans le dossier \textbf{src}. \\

Pour effectuer des tests sur les modèles, utilisez les fichiers situés dans le dossier \textbf{src/expériences}. 
Les instructions d’exécution sont indiquées en en-tête de chaque fichier d’expérience.
